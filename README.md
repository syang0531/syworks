# SY Works

**이미 캔 잡템을 다시 쓸모 있게 만드는 기계들.** 새 아이템은 하나도 넣지 않는다 —
바닐라 아이템이 들어가서 바닐라 아이템으로 나온다.

Minecraft **26.2** / **NeoForge 26.2** (Java 25) 모드. Stan Yang의 모드 가족(`sy…`)으로
[SY Village](https://www.curseforge.com/minecraft/mc-mods/syvillage)·SY Dungeon·SY Magic과
같은 스택이라 함께 플레이할 수 있고, **어느 것에도 의존하지 않는다.**

> ### ⚠ 0.4.0은 이전 버전과 완전히 다른 모드다
>
> 0.3.0까지 이 모드는 **SY Alchemy**였고, 바닐라 블록에서 금속을 뽑아 합금 장비를 만들었다.
> 그 축을 **전부 들어냈다** — 금속 10종·합금 10종·장비 90종·합금로가 사라졌다.
>
> 이유는 간단하다. 합금 장비는 **힘이라는 하나의 축에서 바닐라와 정면으로 경쟁**했고,
> 거기엔 이길 수 있는 칸이 없었다. 다이아보다 약하면 안 쓰이고, 같은데 더 어려우면 안 쓰이고,
> 같은데 더 쉬우면 바닐라 진행이 무의미해지고, 더 강하면 바닐라 엔드게임과 던전 보상이 죽는다.
> 실제로 강철(내구 1400·공격 7.0)은 다이아(1561·7.0)보다 **약간 나쁜데 제작 단계는 다섯 배**였다.
>
> 전체 진단과 새 설계는 [docs/정체성-재설계.md](docs/정체성-재설계.md).
> **0.3.0 이전 월드와 호환되지 않는다.**

## 무엇을 하는 모드인가

플레이하다 보면 쓸 데 없는 것이 쌓인다. 조약돌 몇 스택, 화강암·섬록암·안산암, 흙,
던전에서 뜯어온 계단과 담장, 해체하고 남은 판자와 울타리. 대부분 용암에 버린다.

이 모드는 그것들을 **바닐라가 이미 아는 무언가로** 돌려준다. 그리고 **경험치**를 준다.

기계는 **물리적 공정**으로 나뉜다. 바닐라가 화로 옆에 훈연기와 용광로를 둔 것과 같은 방식이라,
표를 외울 필요 없이 손에 든 게 뭔지만 보면 어디에 넣을지 알 수 있다.

> **광석은 굽고, 돌은 부수고, 나무는 숯으로.**

| 기계 | 공정 | 받는 것 | 주는 것 |
|---|---|---|---|
| **배소로** | 열처리 | 섬손으로 캔 광석 | 추가 산출 + 경험치 |
| **분쇄기** | 분쇄 | 암석 전부 + 계단·담장·슬래브 + 흙 | 자갈 → 모래, 점토, 뼛가루 + 경험치 |
| **숯가마** | 건류 | 화로가 거부하는 나무 제품 전부 | 숯 + 경험치 |

**섬손 채굴이 이 모드의 핵심이다.** 바닐라에서 섬손은 채굴 수율 면에서 순수한 손해라
진지한 광부는 전부 행운을 낀다. 배소로가 섬손 광석에 보너스를 주면 **행운이냐 섬손이냐가
진짜 갈림길**이 된다. 상위 호환이 아니라 대안이 되도록 맞춘다.

## 무엇을 하지 않는가

- **새 아이템을 만들지 않는다.** 꼭 필요하지 않은 새 아이템은 플레이를 돕지 않고 방해한다.
- **진행에 쓰이는 것을 만들어 내지 않는다.** 철·금·다이아·네더 석영·화약은 산출물이 아니다.
  기준은 "쓸모가 있느냐"가 아니라 **"쌓여서 진행이 되느냐"** 다.
- **바닐라의 일을 빼앗지 않는다.** 마법부여대도, 주민 거래도, 상자 보상도 그대로다.

## 현재 구현 상태

- ✅ 0.3.0 잔재(금속·합금·장비·합금로) 삭제, `syalchemy` → `syworks` 개명
- ✅ **기계 공통 틀** — 표 한 줄(`ModMachine`)로 블록·블록엔티티·메뉴·화면·레시피 타입이 전부 따라온다
- ✅ **분쇄기** — 암석 101종(계단·담장·슬래브 포함) → 자갈 → 모래, 응회암 → 점토, 방해석 → 뼛가루, 흙 → 모래
- ✅ **경험치 산출** — 꺼낼 때 지급(바닐라 화로와 같다). 호퍼로 빼면 경험치는 안 나온다
- ⏳ 숯가마 · 추출로를 배소로(섬손 전용)로 전환

## 요구 사항

- **JDK 25** — 없으면 Gradle(foojay 툴체인)이 `~/.gradle/jdks`에 자동으로 받는다.
- Gradle은 별도 설치 불필요 — 포함된 Gradle Wrapper(`gradlew`)가 자동 처리.

## 빌드 & 실행

```powershell
.\gradlew.bat runData      # 모델·영문 lang·레시피 생성
.\gradlew.bat runClient    # 개발용 클라이언트
.\gradlew.bat compileJava  # 컴파일만
.\gradlew.bat build        # 배포용 jar (build/libs/)
```

블록 텍스처는 `tools\gen_block_textures.ps1`이 바닐라 화로 텍스처를 리컬러해 만든다.

## 구조

```
src/main/java/com/syang/syworks/
├── SyWorks.java                메인 (@Mod)
├── registry/                   DeferredRegister (blocks, block entities, menus, recipes, tab)
├── world/level/block/          기계 블록 + BlockEntity
├── world/item/crafting/        커스텀 레시피 타입
└── datagen/                    모델·영문 lang·레시피 생성기
```

진행 상황과 함정은 [docs/진행상황.md](docs/진행상황.md).
