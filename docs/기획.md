# SY Alchemy (옛 이름 Yame) — 기획서

> ⚠️ **0.3.0 기준으로 이 문서의 일부는 더 이상 유효하지 않다.**
> · §5 마법 시스템과 지팡이는 전부 **별도 모드 `symagic`으로 분리**되어 이 모드에서 삭제됐다.
> · §6 Phase 2(초경합금)·Phase 2.5(백금족)는 **삭제**됐다. 상한이 네더라이트 ×2를 넘어 바닐라와 SY Dungeon 보상을 덮어썼다.
> · 합금 로스터 재편(10종 → 6종 수평화)과 조각 경제는 **[재설계-제안.md](재설계-제안.md)** 에서 다룬다. 현재 진행 방향은 그 문서가 기준이다.

> **모드 개요**: Java 1.21.1 / NeoForge 기반. 기존 바닐라 자연블록을 **추출**해 새로운 순수 금속을 얻고, 이를 **합금**하여 청동·강철·티타늄 등 확장 장비를 제작하는 모드.

## 1. 핵심 컨셉

- **새 광석을 월드에 추가하지 않는다.** 화강암·섬록암·점토처럼 이미 널려있는 바닐라 자연블록을 **추출기**에 넣으면, 그 안에 미량 함유된 금속이 나온다. (예: 화강암을 캐서 주석을 얻는 게 아니라, 화강암을 **추출기에 넣어야** 주석이 나온다.)
- 추출한 순수 금속은 대부분 그 자체로는 장비가 되지 않고, **합금로**에서 2종 이상을 섞어야 장비용 재료가 된다. → "합성/추출"이 게임플레이로 강제됨.
- 광물학·금속학에 기반한 **현실적인 소스 매핑**을 지향한다.

### 제작 흐름

```
[1] 추출:  바닐라 자연블록  ──(추출기)──▶  순수 금속 잉곳
[2] 합금:  순수 금속 2종 이상  ──(합금로)──▶  합금 잉곳
[3] 제작:  합금 잉곳  ──(제작대)──▶  도구 · 무기 · 방어구
```

## 2. 순수 금속 10종 ↔ 추출 소스

새로 추출하는 금속 10종. 바닐라 **구리·철·금**은 그대로 재활용(추출 불필요).

| 금속 | 추출 소스 (바닐라 블록) | 현실 근거 |
|------|------------------------|-----------|
| 주석 (Tin) | 화강암 Granite | 주석석(cassiterite)은 화강암·페그마타이트에 산출 |
| 아연 (Zinc) | 섬록암 Diorite | 섬아연석(sphalerite) 열수광상 |
| 니켈 (Nickel) | 안산암 Andesite | 니켈은 고철질/초고철질 화성암에 집중 |
| 알루미늄 (Aluminum) | 점토(블록) Clay | 보크사이트=점토질 광석, 알루미늄 주 원료 |
| 은 (Silver) | 심층암 Deepslate | 은은 깊은 열수맥·방연석과 함께 산출 |
| 크롬 (Chromium) | 응회암 Tuff | 크로마이트는 화산성 고철질암 계열 |
| 티타늄 (Titanium) | 현무암 Basalt | 티탄철석(ilmenite)이 현무암에 풍부 |
| 코발트 (Cobalt) | 블랙스톤 Blackstone | 코발트는 니켈·황화물 광상 동반 |
| 텅스텐 (Tungsten) | 네더 석영 Quartz | 텅스텐(wolframite)은 석영맥에 산출 |
| 황 (Sulfur) | 네더랙 Netherrack | 화산성 유황 — 강철/화약 부산물용 |

## 3. 합금 10종 ↔ 조합 레시피

합금로에서 순수 금속(및 바닐라 금속/탄소)을 조합해 제작.

| 합금 | 조합 | 비고 |
|------|------|------|
| 청동 Bronze | 구리 + 주석 | 고전 기본 합금 |
| 황동 Brass | 구리 + 아연 | 장식/마법 친화 |
| 양은(콘스탄탄) | 구리 + 니켈 | 고내구 저가형 |
| 두랄루민 Duralumin | 알루미늄 + 구리 | 경량 고속 |
| 강철 Steel | 철 + 탄소(석탄/목탄) | 범용 주력. **상위 합금의 재료이기도 함** |
| 스테인리스강 | 철 + 크롬 + 니켈 | 부식 없음 = 초고내구 |
| 티타늄 합금 | 티타늄 + 알루미늄 | 경량 고강도 |
| 텅스텐강 | 강철 + 텅스텐 | 극한 내구 |
| 코발트강(다마스쿠스강) | 강철 + 코발트 | 최종 티어, 전면 우수 |
| 일렉트럼 Electrum | 금 + 은 | 마법 특화 |

### 테크트리 깊이

강철은 그 자체로 장비이면서 상위 합금의 재료가 된다:

```
철 ──▶ 강철 ──▶ 텅스텐강 ──▶ (Phase 2) 초경합금
                └▶ 코발트강
```

### 밸런스 원칙

- **4대 계열 규칙**: 구리계=철급 / 철계=다이아급 / 티타늄계=네더라이트급 / 강철계=네더라이트 이상.
- **⚡두랄루민 · ✨일렉트럼은 특수형** — 순수 파워 대신 한 스탯(속도/인챈트)을 극단화해 개성 부여.
- **현재 1차 상한 = 네더라이트 ×1.3** (내구 ~2600). 천장을 다 쓰지 않고 남겨둔다.
- **네더라이트 ×2(내구 ~4000)는 Phase 2 캡스톤으로 예약.** "2배"는 **내구도 기준**이며, 공격력은 밸런스 안전을 위해 +2~3 선에서 멈춘다(2배 금지 — 전투 붕괴).

## 5. 기능 블록 (커스텀)

### 추출기 (Extraction Furnace)

- **역할**: 바닐라 자연블록 → 순수 금속.
- **작동**: 화로형(연료 + 시간). 입력 슬롯 1 + 연료 슬롯 1 + 출력 슬롯 1.
- **확장 여지**: 부산물(예: 화강암 추출 시 자갈), 금속별 수율 차등, 상위 추출기 업그레이드.

### 합금로 (Alloy Furnace)

- **역할**: 순수 금속 2~3종 → 합금 잉곳.
- **작동**: 화로형(연료 + 시간). 입력 슬롯 2~3 + 연료 슬롯 1 + 출력 슬롯 1.
- **필요성**: 바닐라 화로는 입력 슬롯 1개라 합금(다중 입력)이 원천적으로 불가능 → 전용 블록 필수.

두 블록 모두 `BlockEntity + Menu + Screen(GUI) + 커스텀 RecipeType` 구조로 구현.

## 6. Phase 구성

### Phase 1 — 코어 (현재 목표)

- 순수 금속 10종 + 합금 10종 아이템 등록
- 추출기 · 합금로 블록 (BlockEntity / Menu / GUI / RecipeType)
- 추출 레시피(블록→금속), 합금 레시피(금속→합금)
- 합금별 장비 세트 (도구 5종 + 방어구 4종 — 범위는 §7에서 결정)
- 상한: 네더라이트 ×1.3

### Phase 2 — 엔드게임 캡스톤 ✅ 완료

- **초경합금(텅스텐 카바이드, WC)** = 텅스텐강×2 + 석탄(탄소)×1 + 코발트×1 → 합금로. 현실에서 가장 단단한 공구 소재.
  - 성능: 내구 4064 (네더라이트 ×2), 검 공격력 10, 채굴속도 11, 인챈트 15.
  - **시그니처 퍽: 화염 저항** — 잉곳·도구·방어구 전부 용암/불에서 안 탐(네더라이트식 `.fireResistant()`).
  - 테크트리: `철 → 강철 → 텅스텐강 → 초경합금` (합금로 3단계).
  - 데이터 주도 설계로 `ModAlloy`에 항목 1개 추가만으로 잉곳+장비 9종+제작 레시피 9종+이름+텍스처가 전부 자동 생성됨.
### Phase 2.5 — 백금족 확장 ✅ 완료

- **백금 (Platinum)** — 순수 금속. **고대잔해(Ancient Debris)에서 극저효율 추출**(처리시간 800틱). 화염 저항. 광물학적으로 백금족은 운석에 산출 → 고대잔해가 적합.
- **백금 초합금 (Platinum Superalloy)** = 초경합금×1 + 백금×1 → 합금로. **절대 최종 티어.**
  - 성능: 내구 4600 (네더라이트 ×2.25), 검 공격력 11, 채굴속도 12, 인챈트 22, 화염 저항.
  - 방어구 프리셋 `SUPERALLOY`: 내구 배수 84, 강인함 6, 넉백저항 0.3.
  - **최종 테크트리**: `철 → 강철 → 텅스텐강 → 초경합금` + `고대잔해 → 백금` → **백금 초합금**. 게임 내 가장 깊은 제작 경로.

- [x] **원자재 단계 유무** — **추출기가 잉곳을 직접 산출** (raw 덩어리 단계 없음).

## 8-1. 구현 진행 상황

- **뼈대 완료**: 금속 10종·합금 10종 잉곳, 합금별 검·곡괭이(커스텀 티어), 크리에이티브 탭, 한/영 이름, 데이터 생성기, 플레이스홀더 텍스처.
- **추출기 완료** ✅: `ExtractionFurnaceBlock`(EntityBlock) + `ExtractionFurnaceBlockEntity`(연료+진행도) + `ExtractionFurnaceMenu`/`ExtractionFurnaceScreen`(바닐라 화로 GUI 재사용) + 커스텀 `ExtractionRecipe` 타입/직렬화기 + 추출 레시피 10종(블록→금속) + 아이템 핸들러 캐패빌리티(호퍼 자동화).
- **합금로 완료** ✅: `AlloyFurnaceBlock` + `AlloyFurnaceBlockEntity`(입력 3슬롯) + `AlloyFurnaceMenu`/`AlloyFurnaceScreen`(커스텀 GUI) + 다중 재료 `AlloyRecipe`(`SizedIngredient` 기반, 순서 무관 매칭) + 합금 레시피 10종. `철→강철→텅스텐강/코발트강` 테크트리 포함.
- **장비 풀세트 완료** ✅: 합금 10종 각각 도구 5종(검·곡괭이·도끼·삽·괭이) + 방어구 4종(투구·흉갑·레깅스·부츠). 커스텀 `ArmorMaterial` 10종 등록(`ModArmorMaterials`), 방어력·강인함·넉백저항은 브래킷별 프리셋(`ModAlloy.ArmorPreset`).
- **장비 제작 레시피 완료** ✅: `ModRecipeProvider`(데이터젠)로 합금 10종 × 장비 9종 = 90개 표준 바닐라 패턴 레시피 자동 생성(잉곳+막대기). `광석블록→추출기→합금로→제작대→장비` 전체 서바이벌 루프 완성.
- **Phase 2 초경합금 + 백금족 완료** ✅: 합금 12종(초경합금·백금 초합금), 금속 11종(백금). 최종 테크트리 완성.
- **런타임 검증 완료**: 데디케이티드 서버 부팅, `Loaded 1421 recipes` 파싱 오류 0 (모드 레시피 131종: 추출 11 + 합금 12 + 제작 108). 아이템 약 140종·방어구 재질 12종 등록 정상.
  - 검증 중 발견·수정한 버그: 합금 레시피가 `SizedIngredient.NESTED_CODEC`(중첩 형식)로 파싱돼 flat JSON과 불일치 → `FLAT_CODEC`로 교체하여 해결.
- **다음 단계 후보**: (a) 실제 텍스처 아트(현재 플레이스홀더), (b) 인게임 플레이 밸런스 튜닝.
