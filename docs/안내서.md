## 1. 모드 개요

**새 광석을 월드에 추가하지 않습니다.** 화강암·섬록암·점토처럼 이미 널려 있는 바닐라 자연 블록을
**추출로**에 넣으면 그 안에 미량 함유된 금속이 나옵니다. 순수 금속은 대부분 그 자체로는 장비가 되지 않고,
**합금로**에서 2~3종을 섞어야 장비 재료가 됩니다.

```
[1] 추출:  바닐라 자연 블록  ──(추출로)──▶  순수 금속 주괴
[2] 합금:  순수 금속 2~3종   ──(합금로)──▶  합금 주괴
[3] 제작:  합금 주괴         ──(제작대)──▶  도구 · 방어구
```

**추천 진행 순서**: 추출로 → 청동 장비 → 합금로 → 강철 → 상위 합금.

## 2. 1단계 · 기계 2종 만들기

두 기계 모두 **바닐라 재료만으로** 만들 수 있어 맨 처음부터 시작할 수 있습니다. 작업대에서 제작합니다.

### 추출로 (Extraction Furnace)
자연 블록에서 순수 금속을 뽑는 입문 기계. **화로를 철 8개로 감쌉니다.**

```
철  철  철
철 화로 철
철  철  철
```

### 합금로 (Alloy Furnace)
순수 금속을 섞어 합금을 만드는 기계. **용광로를 구리 8개로 감쌉니다.**

```
구리  구리   구리
구리 용광로 구리
구리  구리   구리
```

## 3. 2단계 · 금속 추출 (추출로)

### 사용법
1. 추출로를 우클릭해 GUI를 엽니다.
2. **연료 슬롯**에 석탄 등 연료를, **입력 슬롯**에 아래 자연 블록을 넣습니다.
3. 진행바가 차면 순수 금속 주괴가 나옵니다. 호퍼로 자동화할 수 있습니다.

모든 추출은 처리 시간 **200틱(10초)**, 블록 1개당 주괴 1개입니다.

### 추출 레시피 (10종)

| 순수 금속 | 입력 자연 블록 | 어디서 구하나 |
|---|---|---|
| 주석 (Tin) | 화강암 Granite | 지표·동굴 어디나 |
| 아연 (Zinc) | 섬록암 Diorite | 지표·동굴 어디나 |
| 니켈 (Nickel) | 안산암 Andesite | 지표·동굴 어디나 |
| 알루미늄 (Aluminum) | 점토 Clay | 강가·습지 바닥 |
| 은 (Silver) | 심층암 Deepslate | Y 0 아래 |
| 크롬 (Chromium) | 응회암 Tuff | 심층 · 지오드 주변 |
| 티타늄 (Titanium) | 현무암 Basalt | 현무암 삼각주 · 용암 접촉면 |
| 코발트 (Cobalt) | 흑암 Blackstone | 네더 현무암 삼각주 |
| 텅스텐 (Tungsten) | 네더 석영 Quartz | 네더 |
| 황 (Sulfur) | 네더랙 Netherrack | 네더 |

> 바닐라 **구리·철·금**은 그대로 재활용하며 추출하지 않습니다.

## 4. 3단계 · 합금 제조 (합금로) + 테크트리

### 사용법
1. 합금로 GUI에 **연료** + **입력 슬롯 3칸**에 재료 금속을 넣습니다.
2. 재료 배치 **순서는 상관없습니다.**
3. 결과 합금 주괴가 지정 개수만큼 나옵니다.

### 합금 레시피 (10종)

| 합금 | 재료 | 결과 | 처리 시간 |
|---|---|---|---|
| 청동 (Bronze) | 구리 ×3 + 주석 ×1 | ×4 | 200t |
| 황동 (Brass) | 구리 ×3 + 아연 ×1 | ×4 | 200t |
| 양은 (Constantan) | 구리 ×2 + 니켈 ×2 | ×4 | 200t |
| 두랄루민 (Duralumin) | 알루미늄 ×3 + 구리 ×1 | ×4 | 200t |
| 일렉트럼 (Electrum) | 금 ×1 + 은 ×1 | ×2 | 200t |
| 강철 (Steel) | 철 ×3 + 석탄 ×1 | ×3 | 250t |
| 스테인리스강 (Stainless Steel) | 철 ×2 + 크롬 ×1 + 니켈 ×1 | ×4 | 250t |
| 티타늄 합금 (Titanium Alloy) | 티타늄 ×2 + 알루미늄 ×1 | ×3 | 300t |
| 텅스텐강 (Tungsten Steel) | 강철 ×2 + 텅스텐 ×1 | ×2 | 400t |
| 코발트강 (Cobalt Steel) | 강철 ×2 + 코발트 ×1 | ×2 | 400t |

### 테크트리

```
철 ─► 강철 ─┬─► 텅스텐강   (최고 내구)
            └─► 코발트강   (최고 채굴속도)
```

강철은 그 자체로 다이아급 장비이면서 상위 두 합금의 재료이기도 합니다.

## 5. 4단계 · 장비 제작 & 스탯

### 제작법 (바닐라와 동일한 배치)
합금 10종은 각각 **도구 5종 + 방어구 4종** 을 만들 수 있습니다. `X`=합금 주괴, `S`=막대.

| 도구 | 배치 | 도구 | 배치 |
|---|---|---|---|
| 검 | `X`/`X`/`S` | 곡괭이 | `XXX`/`·S·`/`·S·` |
| 도끼 | `XX`/`XS`/`·S` | 삽 | `X`/`S`/`S` |
| 괭이 | `XX`/`·S`/`·S` | | |
| 투구 | `XXX`/`X·X` | 흉갑 | `X·X`/`XXX`/`XXX` |
| 레깅스 | `XXX`/`X·X`/`X·X` | 부츠 | `X·X`/`X·X` |

### 장비 스탯

`검 공격력`은 표시 데미지, `채굴 등급`은 캘 수 있는 광물 티어, `내구도`는 도구 기준입니다.
공격 속도는 검 1.6 · 도끼 1.0 · 곡괭이 1.2 · 삽 1.0 · 괭이 2.0 (바닐라와 동일).

| 합금 | 채굴 등급 | 검 공격력 | 도구 내구도 | 방어 합계 | 방어구 강도 | 넉백 저항 | 인챈트성 |
|---|---|---:|---:|---:|---:|---:|---:|
| 청동 | 철 | 6.0 | 230 | 15 | 0 | 0 | 10 |
| 황동 | 철 | 5.0 | 180 | 15 | 0 | 0 | 18 |
| 양은 | 철 | 6.0 | 320 | 15 | 0 | 0 | 8 |
| 두랄루민 | 철 | 5.0 | 200 | 15 | 0 | 0 | 12 |
| 일렉트럼 | 철 | 5.0 | 150 | 15 | 0 | 0 | **25** |
| 강철 | 다이아 | 7.0 | 1400 | 20 | 2 | 0 | 10 |
| 스테인리스강 | 다이아 | 7.0 | 1800 | 20 | 2 | 0 | 8 |
| 티타늄 합금 | 네더라이트 | 8.0 | 2000 | 20 | 3 | 0.1 | 14 |
| 텅스텐강 | 네더라이트 | 9.0 | 2600 | 24 | 4 | 0.15 | 12 |
| 코발트강 | 네더라이트 | 9.0 | 2400 | 24 | 4 | 0.15 | 16 |

- **방어 합계**는 투구+흉갑+레깅스+부츠 방어도의 합입니다. 파츠별 방어도:
  - 철급(15) = 투구2·흉갑6·레깅스5·부츠2
  - 다이아급(20) = 3·8·6·3
  - 텅스텐강/코발트강(24) = 4·9·7·4
- **인챈트성**이 높을수록(예: 일렉트럼 25) 인챈트 테이블에서 좋은 인챈트가 잘 붙습니다.
- 장비 수리는 같은 합금의 주괴로 모루에서 합니다.

> 텅스텐강·코발트강은 현재 네더라이트보다 강합니다. 바닐라·SY Dungeon 보상과 충돌하는 문제라
> 다음 버전에서 네더라이트 동급으로 내릴 예정입니다 ([재설계-제안.md](재설계-제안.md) §5.1).

## 6. 빠른 시작 치트시트

1. **추출로**(철8+화로) 만들기 → 화강암으로 주석 뽑기.
2. 구리 ×3 + 주석 ×1 → **청동**. 철 광맥을 못 찾아도 철급 장비를 씁니다.
3. **합금로**(구리8+용광로) 만들기 → 철 ×3 + 석탄 → **강철**(다이아급).
4. 네더에서 석영·흑암 → **텅스텐강 / 코발트강**.
5. 인챈트는 바닐라 마법부여대·주민 거래·상자 보상으로 구합니다.
