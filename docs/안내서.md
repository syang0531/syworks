## 1. 모드 개요 — 세 가지 축

SY Alchemy는 서로 이어지는 **세 개의 진행 축**으로 이루어져 있습니다.

| 축 | 핵심 기계 | 내용 |
|---|---|---|
| ⚙️ **금속·합금 제작** | 추출로 → 합금로 | 자연 블록에서 순수 금속 11종을 뽑고, 합금 12종으로 도구·방어구 풀세트를 만듭니다. |
| 📖 **룬 마법 (인챈트)** | 룬 제단 | 룬으로 바닐라 인챈트북 42종을 제작·강화합니다. |
| 🪄 **지팡이 마법 (능동 시전)** | 룬 제단 + 모루 | 주문서를 지팡이에 부여해 우클릭으로 마법을 직접 시전합니다. |

**추천 진행 순서**: 추출로 → 합금로 → 장비 → 룬 제단(인챈트) → 지팡이 마법.
단, **파이어볼트 마법은 지팡이만 만들면 초반부터 무료로 쓸 수 있습니다** (아래 §7 참고).

## 2. 1단계 · 핵심 기계 3종 만들기

세 기계 모두 **바닐라 재료만으로** 제작할 수 있어 맨 처음부터 만들 수 있습니다. 모두 작업대에서 제작합니다.

### 추출로 (Extraction Furnace)
자연 블록에서 순수 금속을 뽑는 입문 기계. **화로를 철 8개로 감쌉니다.**

```
철  철  철
철 화로 철
철  철  철
```

### 합금로 (Alloy Furnace)
순수 금속을 섞어 합금을 만드는 기계. **용광로를 구리 8개로 감쌉니다.**

```
구리 구리 구리
구리 용광로 구리
구리 구리 구리
```

### 룬 제단 (Rune Altar)
룬·인챈트북·주문서를 만드는 마법 기계. **마법부여대를 금 주괴 4 + 청금석 4로 감쌉니다.**

```
금   청금석  금
청금석 마법부여대 청금석
금   청금석  금
```

## 3. 2단계 · 금속 추출 (추출로)

### 사용법
1. 추출로를 우클릭해 GUI를 엽니다.
2. **연료 슬롯**에 석탄 등 연료를, **입력 슬롯**에 아래 자연 블록을 넣습니다.
3. 진행바가 차면 순수 금속 주괴가 나옵니다. (호퍼로 자동화 가능)

> 대부분 처리 시간 **200틱(10초)**. 백금만 **800틱(40초)** 으로 느립니다.

| 니켈 주괴 (Nickel) | 안산암 (Andesite) | 200t |
| 알루미늄 주괴 (Aluminum) | 점토 (Clay) | 200t |

## 4. 3단계 · 합금 제조 (합금로) + 테크트리

2. 재료 배치 **순서는 상관없습니다.**
3. 결과 합금 주괴가 지정 개수만큼 나옵니다.

## 5. 4단계 · 장비 제작 & 스탯

### 제작법 (바닐라와 동일한 배치)
합금 12종은 각각 **도구 5종 + 방어구 4종** 을 만들 수 있습니다. `X`=합금 주괴, `S`=막대.

| 도구 | 배치 | 도구 | 배치 |
|---|---|---|---|
| 검 | `X`/`X`/`S` | 곡괭이 | `XXX`/`·S·`/`·S·` |
| 도끼 | `XX`/`XS`/`·S` | 삽 | `X`/`S`/`S` |
| 괭이 | `XX`/`·S`/`·S` | | |
| 투구 | `XXX`/`X·X` | 흉갑 | `X·X`/`XXX`/`XXX` |
| 레깅스 | `XXX`/`X·X`/`X·X` | 부츠 | `X·X`/`X·X` |

## 6. 5단계 · 룬 마법 — 인챈트북 (룬 제단)

룬 제단은 **모루식 즉시 방식**입니다. **연료가 없고**, 두 입력(base + 촉매)을 넣으면 결과가 출력 슬롯에 **미리보기**로 뜨며, **꺼낼 때** 재료가 소모됩니다. 두 입력 슬롯은 **좌우 순서 무관**입니다.

### 6-1. 룬 만들기
모든 마법의 기본 재료. 룬 제단에 넣습니다.

> **금 주괴 + 청금석 → 룬 (Rune)**

### 6-2. 인챈트북 만들기 & 강화
- **Lv1 제작**: `재료 아이템 + 룬 → 해당 인챈트북 Lv1`
- **레벨업**: `인챈트북 LvN + 룬 → Lv(N+1)` (각 인챈트 최대 레벨까지)
- **룬 소모량**: 인챈트북은 **레벨업 1단계당 룬 1개**. 즉 최대 레벨 책 1권 = 룬 (최대 레벨) 개 + 재료 1개(최초 1회).

### 6-3. 인챈트 부여 방법
완성한 인챈트북은 **바닐라와 똑같이 모루에서** 장비에 부여합니다.
- 모드 장비는 각자 **바닐라와 동일한 인챈트 집합**만 받습니다 (검=검 인챈트, 방어구=파츠별 등).
- 인챈트성 값이 있어 **인챈트 테이블**에서도 부여할 수 있지만, 이 모드의 핵심 획득 경로는 **룬 제단 → 책 → 모루**입니다.

## 7. 6단계 · 지팡이 마법 — 능동 시전

**지팡이(재료) = 원소·스탯**, **주문서(마법책) = 마법 자체**를 담당합니다. **마나는 없고, 제한은 쿨다운뿐**입니다.

### 7-1. 전체 흐름

```
[주문서 제작] 재료 + 룬 ──(룬 제단)──► 마법 주문서
[지팡이 제작] 재료 + 막대2 ──(작업대)──► ○○ 지팡이 (빈 슬롯)
[마법 부여]   지팡이 + 주문서 ──(모루)──► 지팡이(마법 장착)
[선택·시전]   Shift+휠로 마법 전환 → 우클릭 시전 (쿨다운)
```

### 7-2. 지팡이 제작
`X`=재료(합금 주괴 또는 바닐라 재료), `S`=막대. 배치는 아래 고정:

```
· · X
· S ·
S · ·
```

### 7-3. 지팡이 18종 스탯

### 7-4. 원소 6종

| 원소 | 성격 |

| 🔥 화염 (Fire) | 즉발 딜 + 발화 |

| ⚡ 뇌전 (Storm) | 고위력 즉발 + 기동/버프 |
| ✨ 신성 (Holy) | 회복 + 보호 버프 |
| ☘️ 자연 (Nature) | 독·지속 피해 |
| 🌑 어둠 (Shadow) | 약화·저주 |

### 7-5. 주문서 제작 (룬 제단)
`재료 + 룬 → 마법 주문서`. 주문서는 **레벨이 없는 단일 아이템**입니다.

### 7-6. 마법 부여 (모루)
`지팡이 + 주문서 → 마법이 장착된 지팡이` (주문서 소모 + 소량 경험치).
- 지팡이 **슬롯 수까지만** 부여할 수 있습니다. 중복·슬롯 초과·파이어볼트는 거부됩니다.
- **숫돌(Grindstone)** 에 지팡이만 단독으로 넣으면 **부여 마법 + 인챈트가 전부 초기화**됩니다 (내장 파이어볼트만 남음).

### 7-7. 마법 선택 & 시전
- **우클릭** = 현재 활성 마법 시전. 쿨다운 중이면 실패합니다.
- **Shift + 마우스 휠** = 활성 마법 전환 (마법 2개 이상일 때). 핫바 위 HUD에 현재 마법·원소·슬롯이 표시됩니다.
- 시전마다 **내구도 1** 소모. 지팡이 재료로 모루에서 수리합니다.
- ⭐ **파이어볼트는 내장 기본기** — 모든 지팡이가 슬롯 소모 없이 항상 시전할 수 있어, 룬 제단(다이아 필요) 이전 초반부터 마법을 쓸 수 있습니다.

### 7-8. 마법 10종 스탯

`위력`이 붙은 값은 `× 유효 위력`(지팡이 주문위력·친화·마력 인챈트 곱연산)으로 스케일됩니다.
`확산`이 붙은 반경은 마력 확산 인챈트로 추가 확장됩니다.
쿨다운은 **기본값**이며 지팡이 쿨감·친화·신속 시전 인챈트가 추가로 단축합니다(하한 5틱).

## 8. 7단계 · 스태프 전용 인챈트 (신규 인챈트북)

이 모드가 **새로 추가한 인챈트 3종**입니다. 검의 "날카로움"에 대응하는 **지팡이 전용 강화**입니다.

| 인챈트 | 최대 | 효과 | 재료 | 룬 |
|---|:--:|---|---|:--:|
| **마력 (Spell Power)** | V | 마법 데미지·회복·효과 **+20% / 레벨** | 자수정 군집 | ×2 |
| **신속 시전 (Alacrity)** | IV | 유효 쿨다운 **−10% / 레벨** (−80% 상한) | 시계 | ×2 |
| **마력 확산 (Arcane Reach)** | III | 광역 반경·투사체 속도 **+25% / 레벨** | 망원경 | ×3 |

### 획득 & 부여
1. **룬 제단**에서 인챈트북으로 제작합니다 (바닐라 인챈트북과 동일 메커니즘, 레벨업 체인 지원 — 레벨업당 룬 2~3개).
2. **모루**에서 인챈트북을 지팡이에 부여합니다.
   - 지팡이는 일반 인챈트로는 **내구성·수선·소멸 저주** + 위 전용 인챈트 3종만 받습니다.
   - 지팡이는 인챈트성 0이라 **인챈트 테이블에는 뜨지 않습니다** (책 중심 설계).

## 9. 빠른 시작 치트시트

1. **추출로**(철8+화로) 만들기 → 화강암·심층암 등으로 순수 금속 뽑기.
2. **합금로**(구리8+용광로) 만들기 → 청동/강철부터 시작해 장비 제작.
3. 테크: `강철 → 텅스텐강 → 초경합금 → 백금 초합금`, `고대잔해 → 백금`.
4. **룬 제단**(마법부여대+금4+청금석4) 만들기 → **금+청금석 = 룬**.
5. 룬으로 **인챈트북 42종** 제작·강화 → 모루로 장비 강화.
6. **지팡이 제작**(재료+막대2) → 바로 **파이어볼트 우클릭** 사용 가능.
7. 룬 제단에서 **주문서** 제작 → **모루**로 지팡이에 마법 부여 → **Shift+휠**로 전환, **우클릭** 시전.
8. **스태프 전용 인챈트**(마력/신속시전/마력확산)로 지팡이 강화.
