## 1. 빌드 & 실행

```powershell
.\gradlew.bat compileJava   # 컴파일
.\gradlew.bat runData       # 모델·en_us·레시피 생성 → src/generated/resources
.\gradlew.bat runClient     # 개발용 클라이언트
.\gradlew.bat runServer     # 데디케이티드 서버 (run/eula.txt 이미 있음)
.\gradlew.bat build         # build/libs/syworks-<ver>.jar
powershell -ExecutionPolicy Bypass -File tools\gen_block_textures.ps1   # 기계 블록 텍스처
powershell -ExecutionPolicy Bypass -File tools\gen_logo.ps1             # CurseForge 로고
```

**Gradle 데몬이 꺼져 있다.** `runServer`/`runClient`는 계속 떠 있으니 로그를 읽고 따로 죽여야 한다.

```powershell
Get-CimInstance Win32_Process | Where-Object { $_.Name -eq 'java.exe' -and $_.CommandLine -like '*Projects\syalchemy*' } | Stop-Process -Force
```

> 폴더 이름은 아직 `C:\Projects\syalchemy`다. 저장소·modid만 `syworks`로 바꿨다. §6 참고.

## 4. 남은 일 (0.4.0)

순서대로. 상세 설계와 수치는 전부 [정체성-재설계.md](정체성-재설계.md)에 있다.

1. **분쇄기(Crusher)** — 제일 많이 돌아갈 기계. `#syworks:crushable` 태그 하나 + `crushable/half`(슬래브).
   `암석 → 자갈 → 모래`, 응회암 → 점토, 방해석 → 뼛가루, 흙 → 모래
2. **숯가마(Charcoal Kiln)** — 화로가 거부하는 나무 제품 전부. **통나무 환산값 × 2**
3. **배소로(Ore Roaster)** — 지금의 추출로를 섬손 광석 전용으로 전환. 블록 id도 이때 바꾼다
4. **경험치 산출** — 모든 기계가 준다. 바닐라 화로처럼 꺼낼 때 지급
5. README·CurseForge 등록정보 갱신, SY Dungeon과 한 세션 플레이

### ⚠ 수치를 정하기 전에 반드시 볼 것

정체성-재설계.md §6의 **복제 구멍 셋**. 요약하면 — 석재 절단기가 **1블록 → 슬래브 2개**를 주므로
슬래브는 반으로 쳐야 하고, 통나무 1 = 판자 4 = 슬래브 8 = 막대기 8이므로 숯가마는
**통나무 환산 × 2** 한 줄로 전부 닫힌다.

### 구현 메모

- `ExtractionRecipe`는 **입력 개수가 1 고정**이다. 슬래브 규칙을 쓰려면 개수 필드가 필요하다.
  지운 `AlloyRecipe`가 `SizedIngredient`로 하던 방식을 git 기록에서 꺼내 쓰면 된다.
- 기계를 하나 더 만드는 건 **추출로 일습을 복사**하는 일이다 —
  Block · BlockEntity · Menu · Screen · RecipeType/Serializer/BookCategory · 등록 5곳 · 블록 텍스처.

## 5. 이 코드베이스의 함정 (다음 세션 필독)

### 26.2 / NeoForge 26.2 API

- **레시피 결과는 `ItemStackTemplate`** — `ItemStack.CODEC`을 쓰면 레시피 로드 시
  `Item … does not have components yet`로 터진다.
- **Ingredient JSON은 그냥 문자열**(`"minecraft:granite"`). NeoForge `SizedIngredient`는
  **`FLAT_CODEC`**(`{"ingredient":…,"count":N}`)을 써야 한다 — `NESTED_CODEC`은 형식이 다르다.
- **`RecipeSerializer`는 record**(codec, streamCodec).
- **기계 레시피는 `isSpecial()` + `PlacementInfo.NOT_PLACEABLE`** — 아니면 클라이언트가
  레시피마다 "can't be placed" 로그를 뱉는다.
- **BlockEntity는 `ItemStacksResourceHandler`**(transfer API) + `ResourceHandlerSlot`,
  드랍은 `preRemoveSideEffects`, 저장은 `ValueInput`/`ValueOutput`.
- **GUI 텍스트 색은 ARGB**(`0xFFFFFFFF`). `GuiGraphicsExtractor`/`extractBackground`/`RenderPipelines.GUI_TEXTURED`.
- **datagen은 전부 `GatherDataEvent.Client`** — 별도 서버 런이 없다.
- **화로 불꽃·화살표는 `furnace.png`에 없다.** 스프라이트로 분리됐다:
  `minecraft:container/furnace/{lit_progress,burn_progress}`. `blitSprite(...)`로 그린다.
- **tick 진행도 3분기** — (불O+처리O→진행), (불O+처리X→즉시 0), (불X+진행>0→서서히 감소).
  바닐라 화로와 같게.

### 이 머신

- **파일이 CRLF다.** `perl -0pi -e`로 여러 줄을 지울 땐 패턴에 `\n`이 아니라 `\R`을 쓴다.
  치환문 쪽에는 `\R`을 못 쓰니 `\r\n`을 직접 쓴다.
- **`git ls-files`는 한글 파일명을 8진수로 escape 한다.** 일괄 치환을 돌리면 `docs/기획.md` 같은
  파일이 **조용히 빠진다.** `git -c core.quotepath=false ls-files`를 쓸 것.
- **일괄 치환에 PNG를 넣지 말 것.** 실제로 로고를 한 번 깨뜨렸다(`git checkout`으로 복구).
- **일괄 개명은 과거 이력도 바꾼다.** CHANGELOG의 "Yame → SY Alchemy" 같은 문장은 손으로 되돌려야 한다.
- **`python`을 호출하지 말 것** — Windows Store 스텁이 입력을 기다리며 멈춘다. perl이나 PowerShell `System.Drawing`.
- **PowerShell/Gradle 로그가 UTF-16일 수 있다.** grep 전에 `tr -d '\000'`.
- **26.2 API 참조**: `build/moddev/artifacts/minecraft-patched-26.2.0.88-sources.jar`를 풀어서 grep.
  바닐라 데이터(레시피·태그 JSON)는 `minecraft-patched-26.2.0.88.jar` 안에 있다.
